# Dataset

This project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The raw CSV files are not included in this repository.

Dataset source:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset should be downloaded separately and imported into the PostgreSQL database according to the SQL scripts and project documentation.

Please review the dataset's current licensing and usage terms before redistributing the raw files.
